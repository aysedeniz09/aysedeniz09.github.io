Computational Social Science: Visuals and Text

Developing and applying computational methods — topic modeling, visual analysis, LLM-assisted classification, and open-source tools — for large-scale text and image data, including how visual framing and data visualizations shape political meaning-making.

  • vistopics — Python package for video and image topic modeling. PyPI
  • Arabic and English OCR — tools for OCR processing of Arabic and English visual text data
